배포 방법
1) GitHub 저장소의 index.html, styles.css, app.js를 각각 이 폴더의 파일로 교체하세요.
2) favicon.ico, favicon-32x32.png, apple-touch-icon.png는 기존에 잘 적용되어 있으면 그대로 두어도 됩니다.

수정 내용
- 조회 기준을 주간 조회 / 월별 조회로 분리
- 주간 선택과 월별 선택을 명확히 분리
- 상단 로데이터 엑셀 내려받기 버튼 추가
- 차트 숫자 라벨 표시 추가
- 지표 그룹 구성 설명과 현재 수치 표시 보강
- 예약신청 단독 차트를 연결콜 + 예약신청 전환 지표 차트로 변경
- 부정리뷰는 명시적인 부정리뷰 컬럼이 있을 때만 반영, 없으면 0 처리
- 톡톡상담 컬럼은 톡톡상담/톡톡 상담/톡톡/네이버톡톡 등으로 인식
